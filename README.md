# 📥 YouTube Video Downloader using Python & Streamlit

A simple and user-friendly **YouTube Video Downloader** built with **Python** and **Streamlit** that allows users to download YouTube videos by just pasting the video URL.

---

## 🚀 Features

- 🔗 Download videos using YouTube URL
- 🎞️ Supports multiple video resolutions
- ⚡ Fast and simple downloading process
- 🖥️ Clean and interactive web interface
- 🐍 Built entirely using Python

---

## 🛠️ Tech Stack

- **Python**
- **Streamlit**
- **Pytube / yt-dlp**
- **Requests**
